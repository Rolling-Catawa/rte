Rollingcats Transit Expansion

MTR 4.0 的附属模组。可以精细调整轨道的弯道、坡度和超高，放置自由节点，让轨道可以站人，让列车重联运行，也能让很多旧版资源包在 MTR 4 下正常使用。

需要先安装 MTR 4.0 及以上版本和 Architectury API。

主要功能

自由节点beta.3

节点可以放在方块之间的任意位置，也能贴在墙上、调整朝向，用拖拽手柄移动和旋转。

轨道碰撞箱beta.3

轨道上可以站人、走路。可以设成多列，中间留空。

列车重联与混编beta.3

两组车可以连成一列跑，不同车型也行。每组车的屏幕和车号各自显示正确。

轨道线形

弯道有多种画法，坡道可以设竖曲线，坡度用千分比显示。

超高

弯道可以向内倾斜，车体、视角和车上的玩家会一起倾斜。

复合构建器

画一次隧道或桥梁的截面，沿着轨道一次铺完。遇到弯道和超高会自动跟着转。

接触网规划器

沿轨道自动摆放接触网支柱和导线，间距、高度都能调。需要安装 MSD。

旧版资源包兼容

让很多 MTR 3 时代的车辆资源包在 MTR 4 下能用。每项兼容处理都能单独关掉。

资源包工作台

在游戏里查看和修改车辆资源，导出成资源包，可以连车辆音效一起导出。

JavaScript 脚本

资源包可以用脚本做车内屏幕、动态贴图、声音和粒子。查看手册

旧版资源包

很多 MTR 3 时代的资源包直接放进 MTR 4 会报错或者少功能，RTE 做了一层兼容处理。

322个社区资源包参与测试
567 → 19加载报错条数
2套脚本引擎可选
  • 两套脚本引擎（Rhino 和 GraalJS），资源包可以自己选
  • 某个脚本出错时只暂停它自己，不会拖垮整个游戏
  • 旧包按秒、按 tick 算的时间会自动换算，到站时间显示正确
  • 贴图路径对不上时按文件名查找
  • 自动补上 MTR 4 需要的车门开口
  • 超大贴图自动缩小，减少显存占用

已知问题

  • 部分旧资源包的车辆可能出现车头车尾方向反了、车厢错位。当前版本没能复现，遇到的话请附上车型和截图反馈。
