Rollingcats Transit Expansion

面向 Minecraft Transit Railway 4.0 的轨道几何与建轨工具。把轨道当成可计算的工程对象 —— 曲线有半径,坡度有千分比,弯道有超高。

需要 MTR 4.0+ 与 Architectury API

功能

把轨道当成工程对象来建

自由节点beta.3

节点可放在非整数坐标,支持 Y 轴位移和墙面吸附,用 Gizmo 拖动与旋转。

轨道碰撞箱beta.3

轨道生成可站立的碰撞箱,支持多列排布、中间留空,资源包脚本可自定义布局。

列车重联与混编beta.3

每个车组单独运行脚本,LCD 与车号按车组计算;车头相对的车组之间不画连接处。

轨道几何

四种路径模式:原生、自动贝塞尔、多点曲线拟合、手动贝塞尔。可设半径的竖曲线,坡度以千分比显示。

超高

沿轨道分布的滚转角。车体、镜头与玩家站立平面同步倾斜 —— 坐进车厢能感觉到。

复合构建器

画一次断面,沿线扫出整段隧道或桥梁。弯道自动跟随转向,超高段自动跟随滚转。

接触网规划器

沿轨道自动布置支柱与导线,可调跨距、拉出值、高度、侧别,曲线自适应加密。

旧版资源包兼容

双 JS 引擎、时间基准换算、贴图与门洞适配。每一项都是独立开关,可逐项关闭定位问题。

资源包工作台

游戏内编辑车辆资源,递归 JSON 编辑器加模型预览,导出为 JSON 或自包含资源包。

JavaScript 脚本

Rhino 与 GraalJS 双运行时,脚本驱动列车显示、动态贴图、声音与粒子。查看手册

旧版资源包

补上 MTR 3.x 到 4.0 的断层

MTR 3.x 时代的资源包在 4.0 下会损失不少功能。本模组补的是这个迁移期的断层。

322个社区资源包参与实测
567 → 19加载报错条数
2套 JS 引擎:Rhino 与 GraalJS
  • 双 JS 引擎 —— Rhino 与 GraalJS,资源包用 engine 字段指定
  • 脚本退避 —— 按函数独立退避,单个坏脚本不会每帧每车抛异常
  • 时间基准换算 —— 3.x 按 tick 与秒,4.0 全线以毫秒计,旧包推算的到站时间不再失真
  • 贴图匹配 —— default.png 改为按文件名匹配
  • 门洞推导 —— 按门位置推导 MTR 4 需要的 DOORWAY 部件
  • 贴图降采样 —— 老包常见的 8K 贴图不再撑爆显存
