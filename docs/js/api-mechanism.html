轨道机构

把几段轨道编成一组，挂上服务端 JS 脚本，做成转车台、移车台、开合桥。

RTE 1.0.0-beta.4 起提供。服务端也要安装 RTE。

搭建

  1. 先铺好机构上的每一段轨道：转车台就是桥面那一段加上各股道的接口段，开合桥就是桥面那一段。
  2. 对着其中一段按 R 打开轨道编辑界面，展开“轨道脚本”。
  3. “分组”填一个名字，“脚本”选一个脚本，点“应用到此轨道”。同组的每一段都这样做，分组名要完全一样。

列车开到没有对准的机构前会停下等待。

脚本文件

存在服务器的 config/rte/rail_scripts/ 下，每个 id 对应 <id>.json（名称与引擎）、<id>.server.js（必需）、<id>.client.js（可选，画外观）。 第一次运行时会放入 turntable 与 drawbridge 两个示例。保存脚本需要 OP 或单人游戏房主；给轨道分组需要 OP，或创造模式且就在轨道附近。

服务端入口函数

函数什么时候调用
create(ctx, state, mech)机构建立或脚本重新加载
tick(ctx, state, mech)大约每 tick 一次
onTrainApproach(ctx, state, mech, e)列车开近，默认 300 格内；e.requiredRail 是它要走的那段轨道
onTrainEnter / onTrainLeave / onTrainStop列车驶上、驶离、停在机构上
onRedstone(ctx, state, mech, e)机构轨道两端节点方块的红石信号变化，e.oldPower → e.newPower
onUse(ctx, state, mech, e)玩家空手右键机构轨道的节点方块
onMessage(ctx, state, mech, e)收到列车或别的机构的消息，或 ctx.after 定时到点
onAligned(ctx, state, mech, e)机构转到位
dispose(ctx, state, mech)机构被拆掉或脚本卸载

mech

方法说明
candidates()组内所有轨道，每项有 id、两端坐标和 yaw
activeRail() / targetRail()当前对准的轨道 / 正在转向的轨道
rotateTo(id, 度每秒)转到对准某段轨道，返回 "ok"；有车正在通过时返回 "train_crossing"
animateTo(...) / animateAround(...)以桥面中心 / 指定点为轴转动、平移，开合桥用后者
isMoving() / isAligned() / state()是否在动、是否对准
lock() / unlock()锁定后列车不能通过
holdRed() / releaseSignals()组内轨道信号保持红灯 / 恢复
rails()逐段限速、保持红灯、改碰撞布局
setRedstoneOutput(x, y, z, 强度)让节点方块输出红石信号
send(列车id, 文本) / sendToMechanism(分组, 文本)给列车脚本或别的机构发消息

列车脚本里可以用 train.railScriptsAhead(距离)、train.sendToMechanism(分组, 文本)、train.pollMechanismMessages() 和机构通信。 命令 /rte railscripts reload 重新加载全部脚本，/rte railscripts list 列出机构状态。
