轨道碰撞箱

客户端脚本全局提供 RailCollision，用来设置轨道的可站立碰撞箱。

参数可以传 PathDataCompat、RailCompat 或底层 Rail。 修改会持久化并同步到服务端，相同的配置不会重复发包。游戏内的手动设置方法见 Wiki 的轨道碰撞箱。

设置规则阵列

RailCollision.configure(
    pathData,
    true,
    1.0,
    0.25,
    0.75,
    0.5,
    -0.25,
    0,
    "-2,2"
);

参数依次对应界面里的启用、宽度、高度、单段长度、阵列间距、垂直偏移、横向偏移、多列横向偏移。

只改多列排布

RailCollision.setColumns(pathData, "-2,2");
pathData.rail.setCollisionColumns("-2,2");

完全自定义排布

每个碰撞箱写成 距离,横向偏移,Y偏移,宽度,高度,长度，箱与箱之间用分号分隔。 RailCollision.box(...) 按这个格式生成字符串：

let boxes = [];
for (let d = 0; d <= pathData.rail.getLength(); d += 0.5) {
    boxes.push(RailCollision.box(d, -2, -0.25, 1, 0.25, 0.75));
    boxes.push(RailCollision.box(d,  2, -0.25, 1, 0.25, 0.75));
}
RailCollision.setLayout(pathData, boxes.join(";"));

恢复规则阵列

RailCollision.clearLayout(pathData);
碰撞配置属于世界数据，不适合做逐帧动画。只在配置确实变化时调用。
