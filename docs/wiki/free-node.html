自由节点

可以放在任意位置、任意朝向的轨道节点。

和直线节点的区别

直线节点自由节点
位置方块格点非整数 XYZ，可做 Y 轴位移
朝向水平可调水平角、俯仰，支持墙面与顶面吸附
碰撞箱有没有碰撞箱和原版选框

放置与连接

  • 手持自由节点右键方块表面放置；放在墙面或顶面时自动吸附朝向。
  • 手持 MTR 连接器，对准节点中心右键即可选取或连接，和普通节点一样建轨。
  • 连接到已有轨道的自由节点时，新轨道沿用节点的高度和朝向，与相邻轨道保持一致。

Gizmo 操作

操作方式与 Axiom Builder 的 Gizmo 一致。

操作效果
左键中心点选择节点
按住左键拖动拖动中心点、红绿蓝三根轴、三组平面手柄或旋转环
右键手柄打开参数界面，直接输入坐标和角度
右键方块表面把选中的节点搬到该处
滚轮按视线方向或悬停的轴微调
按住 Ctrl改为 1 格移动、15° 旋转吸附
按住 Shift取消拖动吸附，滚轮精度降到 0.0001
方向键、Page Up / Page Down微调位置
Ctrl+C / Ctrl+V复制、粘贴节点
Ctrl+Z / Ctrl+Y撤销、重做
Delete / Backspace删除节点，相连轨道一并删除

拖动和旋转时，相连轨道实时跟随。

回放

用 ReplayMod 录制时，录制者手持节点工具期间的节点标记、节点模型和 Gizmo（包括拖动和旋转过程）都会出现在回放里。
