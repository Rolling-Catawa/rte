路线路径创建器

把一段段轨道串成一条能跑车的营运线路。校验很严，但错误提示会告诉你卡在哪。

用法

操作结果
右键轨道节点把该节点接进当前线路
空手右键空气打开界面，填线路名与颜色，确认建线
蹲下右键空气撤销上一步

物品的 tooltip 会实时显示已连的每一段 —— 起终点、长度、停站时间， 串到一半也能随时看清进度。

建线流程

  1. 右键第一个站台所在的轨道节点
  2. 沿线依次右键后续节点
  3. 空手右键空气打开界面
  4. 填线路名、选颜色
  5. 确认建线

校验规则

不满足这些条件会被拒绝，并给出对应提示：

规则说明
起点必须是站台线路必须从站台开始
起点不能折返第一站不允许设为折返点
拒绝单向轨单向轨不能纳入线路
折返位置受限非折返轨与非站台之间不允许折返
角度校验相邻段夹角不合理时拒绝
折返点会自动补停站时间，不用手动填。

常见错误

提示原因
必须以站台开始第一个节点不是站台，换个起点
起点不能折返取消第一站的折返标记
非法折返折返点必须在站台或折返轨上
找不到轨道右键的位置没有轨道节点
角度不合法相邻两段的夹角过大
