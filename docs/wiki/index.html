总览

RTE 加入 4 件物品与 3 种方块，全部归在两个创造模式标签页下。这里逐个说明用法。

物品

物品一句话详情
轨道路径编辑器打开轨道编辑界面，改线形、超高、限速查看
路线路径创建器串联轨道节点建成一条营运线路查看
复合创建器画一次断面，沿轨道扫出隧道或桥梁查看
位移工具按轨道几何把自己传送到对应位置查看

方块

方块一句话详情
直线节点强制该处为直线段查看
装饰物件摆放装饰模型，也是沿线阵列的样板查看
自由节点放在任意位置、任意朝向的节点，用 Gizmo 拖动和旋转查看

创造模式标签页

标签页内容
RTE 核心全部工具物品与直线节点、自由节点
装饰物件内置装饰模型，以及资源包提供的自定义物件

详见创造模式标签页。轨道本身的可站立碰撞箱见轨道碰撞箱。

快速上手路线

  1. 拿轨道路径编辑器，对着一段轨道右键，改线形和超高
  2. 用复合创建器画个隧道断面，沿这段线扫出来
  3. 用路线路径创建器把轨道串成营运线路
  4. 摆装饰物件当样板，用沿线阵列铺满整条线
全部工具都支持撤销：蹲下 + 右键空气。
