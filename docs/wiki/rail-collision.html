轨道碰撞箱

让轨道生成真实、可站立的碰撞箱。

碰撞箱参与实体移动计算，不只是调试显示：玩家可以站在上面、沿着走，也可以从上方落到碰撞面上。 服务端和客户端都要装 RTE，碰撞设置随轨道保存并同步。

设置方法

  1. 准星对准轨道按 R，或手持 MTR 轨道刷子 Shift + 右键节点，打开轨道编辑界面。
  2. 勾选「应用轨道碰撞箱」，再勾选「启用碰撞箱」。
  3. 调好参数，用刷子右键轨道应用。
  4. 按 F3+B 可以看到碰撞箱线框。

参数

参数说明
宽度 / 高度 / 单段长度单个碰撞箱的尺寸
阵列间距沿轨道方向相邻碰撞箱的采样距离，0.01～16 m。越小越平滑，计算量越大
垂直偏移相对轨道采样点的 Y 偏移
横向偏移整组碰撞箱相对轨道中心线的偏移
多列横向偏移英文逗号分隔的附加偏移。0 为单列，-2,2 为左右两列、中间留空
每条轨道最多 32 列、8192 个碰撞箱，超出时自动放宽采样间距。反向轨道会自动镜像横向位置和自定义布局。

用脚本控制

资源包脚本可以通过 RailCollision 设置规则阵列，或逐个指定碰撞箱，见 JS 手册的轨道碰撞箱。
